# คู่มือการใช้งานระบบ MarkingTBH

เอกสารนี้อธิบายการใช้งานระบบ MarkingTBH แบบทีละหน้า ตั้งแต่การเข้าสู่ระบบ การสร้างรายการสติ๊กเกอร์ การส่งออก PDF การดูประวัติ และการจัดการ Template สำหรับผู้ดูแลระบบ

## ภาพรวมระบบ

MarkingTBH เป็นระบบสำหรับสร้างข้อมูลสติ๊กเกอร์สินค้า โดยผู้ใช้เลือก Template ของลูกค้า กรอกข้อมูลการผลิตและรายละเอียดในสติ๊กเกอร์ จากนั้นสามารถดู Preview และส่งออกเป็น PDF/สั่งพิมพ์ได้ ระบบจะบันทึกประวัติรายการที่บันทึกหรือพิมพ์ไว้ให้ตรวจสอบย้อนหลัง

หน้าหลักในระบบมี 3 ส่วนหลัก

1. หน้า Marking: ใช้สร้างรายการสติ๊กเกอร์ กรอกข้อมูล และส่งออก PDF
2. หน้า History: ใช้ตรวจสอบประวัติการบันทึก/พิมพ์ และประวัติ Template
3. หน้า จัดการ Template: ใช้เพิ่มหรือแก้ไข Template สำหรับลูกค้า เฉพาะผู้ใช้ที่มีสิทธิ์ Admin

## 1. การเข้าสู่ระบบ

### วิธีเข้าสู่ระบบ

1. เปิดระบบ MarkingTBH ใน browser
2. หากยังไม่ได้เข้าสู่ระบบ ระบบจะพาไปที่หน้า Login อัตโนมัติ
3. กรอกชื่อผู้ใช้ในช่อง "ชื่อผู้ใช้"
4. กรอกรหัสผ่านในช่อง "รหัสผ่าน"
5. หากต้องการตรวจสอบรหัสผ่านที่พิมพ์ ให้กด icon รูปตาเพื่อแสดง/ซ่อนรหัสผ่าน
6. กดปุ่ม "เข้าสู่ระบบ"

### กรณีเข้าสู่ระบบไม่สำเร็จ

หากไม่ได้กรอกชื่อผู้ใช้หรือรหัสผ่าน ระบบจะแจ้งให้กรอกข้อมูลให้ครบ หากชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือนจากหน้า Login

### หลังเข้าสู่ระบบสำเร็จ

เมื่อเข้าสู่ระบบสำเร็จ ระบบจะพาไปยังหน้า Marking ซึ่งเป็นหน้าหลักสำหรับเลือก Template และสร้างสติ๊กเกอร์

## 2. เมนูด้านบน

หลังเข้าสู่ระบบ จะมีแถบนำทางด้านบนสำหรับไปยังหน้าต่าง ๆ ของระบบ

- Marking: หน้าสร้างรายการสติ๊กเกอร์
- ประวัติ: หน้าดูประวัติการบันทึก/พิมพ์ และประวัติ Template
- จัดการ Template: หน้าเพิ่ม/แก้ไข Template เฉพาะ Admin
- Logout: ออกจากระบบ

ถ้าเปิดหน้าอื่นโดยยังไม่ได้ login ระบบจะตรวจสอบ session และพากลับไปหน้า Login หาก session หมดอายุ

## 3. หน้า Marking

หน้า Marking ใช้สำหรับสร้างสติ๊กเกอร์จริงตาม Template ของลูกค้า

### 3.1 เลือก Template

1. ไปที่หน้า Marking
2. ที่ส่วน "รายละเอียดสติ๊กเกอร์" ให้คลิกช่อง Template
3. พิมพ์ค้นหาชื่อลูกค้าหรือ Template
4. เลือก Template ที่ต้องการใช้งาน

หมายเหตุเกี่ยวกับ Template

- Template ที่ Active สามารถเลือกใช้งานได้ตามปกติ
- Template ที่ Inactive จะแสดงอยู่ท้ายรายการ พร้อมสัญลักษณ์บอกว่าใช้งานไม่ได้ และไม่สามารถเลือกเพื่อสร้างรายการ Marking ได้
- ถ้าเลือก Template แล้วระบบจะโหลด field ที่ต้องกรอกให้โดยอัตโนมัติ

### 3.2 เลือก Production Date

หลังเลือก Template จะเห็นช่อง "Production Date"

1. กดช่อง Production Date
2. เลือกวันที่จาก Calendar
3. ระบบจะใช้วันที่นี้ในการคำนวณ Lot เริ่มต้นและบันทึกลงรายการ

ถ้า Template มี field วันที่อื่น ๆ ภายในแบบฟอร์ม ระบบจะแสดง Calendar ให้ตามรูปแบบวันที่ที่ตั้งค่าไว้ใน Template เช่น `02-Sep-2026`, `02/Sep/2026`, หรือ `02 Sep 2026`

### 3.3 กรอกจำนวน Lot ที่ต้องการพิมพ์

ช่อง "จำนวน Lot ที่ต้องการ print" ใช้กำหนดจำนวน Lot ที่จะสร้างสติ๊กเกอร์

- กรอกเป็นตัวเลขเท่านั้น
- ระบบจะแสดง hint ว่าเริ่ม LOT ใด เช่น `เริ่ม LOT 12`
- ถ้าเปลี่ยน Production Date ระบบจะ refresh Lot เริ่มต้นตามข้อมูลเดิมที่เคยบันทึกไว้

### 3.4 กรอกข้อมูลในกรอบ

ส่วน "ในกรอบ" คือข้อมูลที่จะพิมพ์ในสติ๊กเกอร์ในกรอบ

1. กรอกข้อมูลตาม field ที่ Template กำหนด
2. Field ที่เป็นตัวนับ เช่น Lot หรือ Pallet อาจมีค่าเริ่มต้นให้อัตโนมัติ
3. Field ที่ล็อกไว้จะแก้ไขไม่ได้
4. Field ที่เป็น Calendar ให้เลือกวันที่จากปุ่ม Calendar
5. ถ้า field ตั้งค่าให้เป็นตัวพิมพ์ใหญ่ ระบบจะแปลงค่าที่กรอกเป็นตัวใหญ่ให้อัตโนมัติ ยกเว้น field วันที่ที่ต้องรักษารูปแบบเดือน เช่น `Sep`

### 3.5 กรอกข้อมูลนอกกรอบ

ส่วน "นอกกรอบ" คือข้อมูลที่พิมพ์ในสติ๊กเกอร์นอกกรอบ อาจแบ่งเป็นหลาย table หรือหลายกลุ่มได้ตาม Template

1. กรอกข้อมูลในแต่ละกลุ่มที่ระบบแสดง
2. ถ้า Template ไม่มีนอกกรอบ ระบบอาจแสดงข้อความว่าไม่ได้ตั้งค่าสติ๊กเกอร์นอกกรอบไว้
3. Field ที่เป็น section จะมีช่องย่อยหลายช่อง เช่น Section 1, Section 2
4. Field ที่เป็นตัวนับจะเติมค่าตาม Lot/Pallet ให้ตามการตั้งค่า Template

### 3.6 ดู Preview Sticker

ด้านล่างหน้าจอจะมีปุ่ม "ดู Preview Sticker"

1. กดปุ่ม "ดู Preview Sticker"
2. ระบบจะแสดงตัวอย่างสติ๊กเกอร์จากข้อมูลที่กรอก
3. หากมีหลายรูปแบบ เช่น ในกรอบ, นอกกรอบ, ชื่อลูกค้า, FSC logo จะสามารถสลับดูแต่ละแบบได้
4. หากนอกกรอบมีหลายกลุ่ม สามารถสลับดูตามกลุ่มได้

ควรตรวจสอบ Preview ก่อนส่งออกทุกครั้ง โดยเฉพาะ Lot, Pallet, วันที่, จำนวนด้าน, format และข้อมูลเฉพาะลูกค้า

### 3.7 ส่งออก PDF / พิมพ์

1. กดปุ่ม "ส่งออก PDF"
2. ระบบจะเปิดหน้าต่างให้เลือกประเภทสติ๊กเกอร์ที่ต้องการพิมพ์
3. เลือกได้มากกว่า 1 แบบ เช่น ในกรอบ, นอกกรอบ, ชื่อลูกค้า, FSC logo
4. กดปุ่ม "ปริ้นรายการที่เลือก"
5. ระบบจะบันทึกรายการ และเปิดหน้าพิมพ์/PDF

หากยังไม่ได้เลือก Template, ยังไม่ได้กรอก Production Date, จำนวน Lot ไม่ถูกต้อง หรือมี field บังคับที่ยังไม่ได้กรอก ระบบจะแจ้งเตือนและยังไม่ส่งออก

## 4. หน้า History

หน้า History ใช้ตรวจสอบประวัติการใช้งานย้อนหลัง มี 2 โหมดคือ Print และ Templates

### 4.1 โหมด Print

โหมด Print ใช้ดูประวัติรายการ Marking ที่เคยบันทึกหรือพิมพ์

ตารางจะแสดงข้อมูลหลัก เช่น

- เวลา
- ผู้บันทึก
- สาขา
- ลูกค้า
- สิ่งที่พิมพ์
- ปุ่มแสดงรายละเอียด

### 4.2 การค้นหาและกรองประวัติ Print

ใช้แถบค้นหาด้านบนของหน้า History

1. Template: พิมพ์ชื่อลูกค้าหรือ Template เพื่อกรองรายการ
2. ผู้บันทึก: พิมพ์ชื่อผู้บันทึก
3. การทำรายการ: เลือกทั้งหมด, พิมพ์/PDF, บันทึก, หรือข้อมูลเก่า
4. วันที่: เลือกวันที่จาก Calendar
5. ล้าง Filter: กดเพื่อล้างเงื่อนไขทั้งหมด

จำนวนรายการที่แสดงจะเปลี่ยนตาม filter ที่เลือก

### 4.3 ดูรายละเอียดรายการย้อนหลัง

1. ในตารางประวัติ Print กดปุ่ม "แสดง"
2. ระบบจะเปิดหน้าต่างรายละเอียด
3. ภายในหน้าต่างจะแสดงข้อมูล เช่น Production Date, ช่วง LOT, จำนวน LOT, จำนวนด้าน, Format, เกรด, FSC, Other และสิ่งที่พิมพ์
4. ด้านล่างจะแสดงข้อมูลที่กรอกในสติ๊กเกอร์ แยกเป็นในกรอบและนอกกรอบ

### 4.4 โหมด Templates

โหมด Templates ใช้ดูประวัติ Template

ตารางจะแสดงข้อมูล เช่น

- ชื่อ Template
- วันที่สร้าง
- วันที่แก้ไขล่าสุด
- ผู้แก้ล่าสุด
- จำนวน field ในกรอบและนอกกรอบ

สามารถใช้ filter Template และวันที่เพื่อค้นหาข้อมูลได้

## 5. หน้า จัดการ Template

หน้านี้ใช้สำหรับเพิ่มหรือแก้ไข Template เฉพาะผู้ใช้ที่มีสิทธิ์ Admin เท่านั้น หากผู้ใช้ไม่มีสิทธิ์ Admin ระบบจะแสดงข้อความแจ้งเตือนว่าใช้งานหน้านี้ไม่ได้

หน้า จัดการ Template มี 2 โหมด

1. Edit: แก้ไข Template เดิม
2. Create: สร้าง Template ใหม่

## 6. จัดการ Template: โหมด Edit

### 6.1 เลือก Template ที่ต้องการแก้ไข

1. ไปที่หน้า "จัดการ Template"
2. เลือกโหมด Edit
3. ที่ช่อง "เลือก Template" พิมพ์ค้นหา Template
4. เลือก Template ที่ต้องการแก้ไข

ในหน้านี้ Template ที่ Inactive จะแสดงในรายการด้วย เพื่อให้ Admin สามารถเปิดกลับมาแก้ไขหรือเปลี่ยนเป็น Active ได้

### 6.2 แก้ชื่อ Template

หลังเลือก Template แล้ว สามารถแก้ไขชื่อในช่อง "ชื่อ Template" ได้ ชื่อที่พิมพ์จะถูกแปลงเป็นตัวพิมพ์ใหญ่

### 6.3 ตั้งค่า Active / Inactive

ส่วน Status ใช้กำหนดว่า Template นี้พร้อมให้ใช้งานในหน้า Marking หรือไม่

- Active: Template ใช้งานได้ในหน้า Marking
- Inactive: Template ไม่ให้เลือกใช้งานในหน้า Marking แต่ยังเห็นได้ในหน้าจัดการ Template

### 6.4 ตั้งค่าพื้นฐานของสติ๊กเกอร์

ตั้งค่าที่มีผลต่อการสร้างสติ๊กเกอร์ ได้แก่

- จำนวนด้าน Sticker / 1 ลัง: จำนวน side ต่อหนึ่งลัง
- Format: เช่น `5533` หรือ `555`
- เกรด: เช่น `TNR` หรือ `NON TNR`
- Other: เช่น `Dome` หรือ `Inter`
- พิมพ์ logo FSC: ใช้ได้เมื่อเกรดเป็น `TNR`

### 6.5 ส่วน Sticker ในกรอบ

ใช้จัด field ที่พิมพ์ในกรอบ สามารถเพิ่ม, แก้ไข, ลบ และลากจัดลำดับ field ได้

Field เริ่มต้นโดยทั่วไปอาจมีเช่น

- LOT NO.
- PALLET NO.
- GROSS
- NETT
- DESTINATION
- CONTRACT NO.

### 6.6 ส่วน Sticker นอกกรอบ

ใช้จัด field ที่พิมพ์นอกกรอบ โดยสามารถแบ่งเป็น Table ได้

การเพิ่ม Table

1. กด "เพิ่ม Table"
2. เลือกรูปแบบตาราง
3. ระบบจะสร้างกลุ่มนอกกรอบใหม่

รูปแบบตารางที่มี เช่น

- 2 x 2 แนวนอน: เหมาะกับ A4 แนวนอน 4 ดวงต่อหน้า
- 8 x 2 แนวตั้ง: เหมาะกับ A4 แนวตั้ง 16 ดวงต่อหน้า และจำกัดรูปแบบบางอย่างเพื่อไม่ให้ข้อความล้น

ภายในแต่ละ Table สามารถเปลี่ยนชื่อ Table, เปลี่ยน layout, ลากย้าย table, เพิ่มแถว หรือ ลบ table ได้

### 6.7 เพิ่ม Field

เมื่อต้องการเพิ่ม field ให้กด "เพิ่ม Field" หรือ "เพิ่มแถว" ใน Table นอกกรอบ

ระบบจะให้เลือกชนิด field

- Field ปกติ: ช่องข้อมูลทั่วไป
- Section: field แบบแบ่งเป็นส่วนย่อย เช่นมี Section 1, Section 2 และสามารถตั้งให้ section ใดเป็นตัวนับได้

หลังเพิ่มแล้วให้คลิก field เพื่อเปิดหน้าต่างตั้งค่า

### 6.8 ตั้งค่า Field

เมื่อคลิก field จะเปิด modal สำหรับตั้งค่ารายละเอียด

ตั้งค่าหลักที่พบได้

- ชื่อ Field: ชื่อ field ที่จะแสดงในระบบและบนสติ๊กเกอร์
- ล็อกค่าชื่อ field: ใช้ค่า field เป็นค่าคงที่ ผู้ใช้แก้ไม่ได้ตอนกรอก Marking
- ใช้ค่าเริ่มต้น: ให้ระบบเติมค่า default ให้อัตโนมัติ
- ค่า default: ค่าที่จะถูกเติมเมื่อเปิด Template
- ตัวพิมพ์ใหญ่: แปลงค่าที่ผู้ใช้กรอกเป็นตัวพิมพ์ใหญ่
- ไม่พิมพ์ชื่อ Field: พิมพ์เฉพาะค่า ไม่พิมพ์ label
- นับ: ตั้ง field ให้เป็นตัวนับ Lot, Pallet หรือ Sequence
- ใช้ Calendar: เปลี่ยน field เป็น date field
- รูปแบบวันที่: ตั้งรูปแบบวันที่ เช่น `yyyy-mm-dd`, `dd-Mmm-yyyy`, หรือ `dd Mmm yyyy`
- ขนาดใหญ่พิเศษ: ขยายขนาดตัวอักษรบนสติ๊กเกอร์

หมายเหตุ: Field วันที่จะรักษารูปแบบเดือนภาษาอังกฤษแบบตัวแรกใหญ่ เช่น `Sep` ไม่ถูกแปลงเป็น `SEP`

### 6.9 ตั้งค่า Section

Field แบบ Section คือ field ที่มีช่องย่อยหลายช่องภายใน field เดียว เช่น LOT NO. ที่อาจมี Section 1, Section 2

ในแต่ละ Section สามารถตั้งค่าได้ เช่น

- ชื่อ Section
- ข้อความก่อน Section
- ข้อความหลัง Section
- ตั้งให้เป็นตัวนับ
- เลือกชนิดตัวนับ
- ลบ Section
- ลากเพื่อเปลี่ยนลำดับ Section

ปุ่ม `+1` ใช้เพิ่ม Section ใหม่เข้าไปใน field นั้น

### 6.10 ตั้งค่าการนับ

เมื่อกดปุ่ม "นับ" ระบบจะเปิดหน้าต่างตั้งค่าการนับ

ชนิดการนับมี 3 แบบ

- Lot: นับตามเลข Lot ของรอบพิมพ์
- Pallet: นับตามลำดับ Pallet ในแต่ละ Lot
- +1 ไปเรื่อยๆ: นับต่อเนื่องไปเรื่อย ๆ ไม่อิงกับ Lot หรือ Pallet

สามารถเลือก "Default 4 หลัก (0001)" เพื่อให้เลขแสดงเป็น 4 หลัก เช่น `0001`, `0002`

### 6.11 ตั้งค่ารูปแบบวันที่

เมื่อ field เปิด "ใช้ Calendar" แล้ว จะมีปุ่ม "รูปแบบวันที่"

สามารถเลือกส่วนประกอบวันที่ได้ 3 ช่อง เช่น

- วัน
- เดือนตัวเลข
- เดือนย่อ ENG
- ปี

และเลือกตัวคั่นได้ เช่น

- `-`
- `/`
- `.`
- ช่องว่าง

ตัวอย่างรูปแบบที่ใช้ได้

- `2026-09-02`
- `02/Sep/2026`
- `02.Sep.2026`
- `02 Sep 2026`

### 6.12 Preview Template

กด "ดู Preview Sticker" เพื่อดูตัวอย่างสติ๊กเกอร์จาก Template ที่กำลังแก้ไข ระบบจะใช้ข้อมูลจำลอง เช่น text เป็น `xxx` และ number เป็น `0`

ควรใช้ Preview เพื่อตรวจสอบ

- field อยู่ครบหรือไม่
- label ซ่อน/แสดงถูกต้องหรือไม่
- field ใหญ่พิเศษดูเหมาะสมหรือไม่
- ตารางนอกกรอบไม่ล้นหรือเบียดกัน
- format วันที่ถูกต้อง

### 6.13 บันทึกหรือยกเลิก

- กด "บันทึก Template" เพื่อบันทึกการแก้ไข
- กด "ยกเลิก" เพื่อโหลดข้อมูล Template เดิมกลับมา

หากบันทึกสำเร็จ ระบบจะแสดง Toast แจ้งเตือน

## 7. จัดการ Template: โหมด Create

### 7.1 สร้าง Template ใหม่

1. ไปที่หน้า "จัดการ Template"
2. เลือกโหมด Create
3. กรอก "ชื่อ Template"
4. เลือก Status ว่าจะให้ Active หรือ Inactive
5. ตั้งค่าพื้นฐาน เช่น จำนวนด้าน, Format, เกรด, Other และ FSC
6. จัด field ในกรอบและนอกกรอบ
7. กด "สร้าง Template"

### 7.2 คัดลอกจาก Template เดิม

หากต้องการเริ่มจาก Template ที่มีอยู่

1. ที่ช่อง "คัดลอก Template จาก" ให้เลือก Template เดิม
2. ระบบจะคัดลอก field และรูปแบบสติ๊กเกอร์มาให้
3. แก้ไขรายละเอียดตามต้องการ
4. กด "สร้าง Template"

ในช่องนี้สามารถเห็น Template ที่ Inactive ได้ด้วย เพื่อใช้เป็นต้นแบบในการคัดลอก

### 7.3 กรณีชื่อ Template ซ้ำ

หากชื่อ Template ใหม่ซ้ำกับ Template ที่มีอยู่ ระบบจะแสดงหน้าต่างเตือน ให้เลือกว่าจะยกเลิกหรือแทนที่ Template เดิม

ควรตรวจสอบให้แน่ใจก่อนแทนที่ เพราะการแทนที่จะอัปเดต Template เดิมด้วยข้อมูลที่กำลังสร้าง

## 8. ข้อควรระวังในการใช้งาน

- ตรวจสอบ Template ให้ถูกลูกค้าก่อนกรอกข้อมูล
- ตรวจสอบ Production Date ก่อนส่งออก PDF เพราะมีผลต่อ Lot เริ่มต้น
- ตรวจสอบจำนวน Lot และจำนวนด้าน Sticker ก่อนพิมพ์
- ใช้ Preview ทุกครั้งก่อนส่งออก
- หาก Template เป็น Inactive จะไม่สามารถใช้สร้าง Marking ได้
- การแก้ Template ส่งผลกับการใช้งานครั้งถัดไป ควรตรวจสอบ Preview ก่อนบันทึก
- ถ้าใช้ Calendar แบบเดือนย่อ ENG ระบบจะแสดงเดือนแบบตัวแรกใหญ่ เช่น `Sep`
- หากใช้ตัวคั่นวันที่เป็นช่องว่าง ต้องเลือกรูปแบบวันที่จาก modal รูปแบบวันที่ใน Template

## 9. ปัญหาที่พบบ่อย

### เลือก Template แล้วไม่มี field แสดง

ตรวจสอบว่า Template นั้นมีการตั้งค่า field ในกรอบหรือนอกกรอบไว้หรือไม่ หากเป็น Template ใหม่ให้ไปที่หน้า จัดการ Template และเพิ่ม field ก่อน

### Template ที่ต้องการไม่สามารถเลือกได้

หาก Template อยู่ท้าย list และมีสัญลักษณ์ disabled แสดงว่า Template นั้นเป็น Inactive ต้องให้ Admin เข้าไปเปิด Active ก่อนใช้งาน

### ส่งออก PDF ไม่ได้

ตรวจสอบว่า

- เลือก Template แล้ว
- เลือก Production Date แล้ว
- จำนวน Lot เป็นตัวเลขมากกว่า 0
- กรอก field บังคับครบ
- เลือกประเภทสติ๊กเกอร์ในหน้าต่างส่งออกแล้วอย่างน้อย 1 แบบ

### วันที่แสดงไม่ตรงรูปแบบ

ให้ตรวจสอบการตั้งค่า "รูปแบบวันที่" ใน Template ว่าเลือกวัน/เดือน/ปี และตัวคั่นถูกต้องหรือไม่

### ไม่เห็นเมนูจัดการ Template หรือเข้าแล้วใช้งานไม่ได้

หน้านี้ใช้ได้เฉพาะ Admin หากไม่มีสิทธิ์ ระบบจะแสดงข้อความแจ้งเตือน

## 10. สรุป workflow ที่แนะนำ

การพิมพ์สติ๊กเกอร์ประจำวัน

1. Login
2. เข้า Marking
3. เลือก Template ลูกค้า
4. เลือก Production Date
5. กรอกจำนวน Lot
6. กรอกข้อมูลในกรอบ/นอกกรอบ
7. ดู Preview
8. ส่งออก PDF
9. ตรวจสอบรายการย้อนหลังใน History หากต้องการ

การสร้างหรือแก้ Template

1. Login ด้วยบัญชี Admin
2. เข้า จัดการ Template
3. เลือก Edit หรือ Create
4. ตั้งค่าข้อมูลพื้นฐาน
5. เพิ่ม/แก้ไข field ในกรอบและนอกกรอบ
6. ตั้งค่า counter, calendar, default, label และขนาดตัวอักษร
7. ดู Preview
8. บันทึก Template
